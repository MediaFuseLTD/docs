## Welcome

The MediaFuse External API empowers developers and partners to retrieve and seamlessly integrate PR distribution data directly into their own systems and websites.

The same API works for every MediaFuse brand: Chainwire, FinanceWire, CyberNewsWire, GamingWire, TechnologyWire, PlayNewswire and NewsDirect. Only the base URL changes, see [Our Brands](/brands).
